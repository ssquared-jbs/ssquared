Write a Mandarin paragraph about a public service or customs problem. Try to include:

  • one public place, like 邮局, 银行, 医院, 警察局 or 大使馆
  • one document word, like 护照, 签证, 身份证 or 文件
  • one customs word, like 海关, 检查, 行李 or 排队
  • one problem, like 丢了, 忘记, 麻烦 or 问题
  • one polite phrase, like 请问, 麻烦你了 or 谢谢你的帮助
  • one reason using 因为
  • one result using 所以
  • one contrast using 虽然……但是……
