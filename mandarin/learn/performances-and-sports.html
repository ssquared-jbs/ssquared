Performances and Sports

Learn how to talk about shows, competitions, performances, reasons and sports.

1. Shows and events

节目

jiémù

programme / show

晚会

wǎnhuì

evening party / event

音乐会

yīnyuèhuì

concert

广告

guǎnggào

advertisement

我喜欢看音乐会。

I like watching concerts.

Quick check

2. Performances and activities

比赛

bǐsài

competition / match

表演

biǎoyǎn

performance

活动

huódòng

activity

画

huà

to draw / painting

学校有很多活动和比赛。

The school has many activities and competitions.

我喜欢画画儿。

I like drawing pictures.

Check

3. Sports and frequency

体操

tǐcāo

gymnastics

武术

wǔshù

martial arts

跑步

pǎobù

running

足球

zúqiú

football

总是

zǒngshì

always

常常

chángcháng

often

我常常跑步，也喜欢踢足球。

I often run and also like playing football.

4. Giving reasons

因为

yīnwèi

because

非常

fēicháng

extremely / very

我喜欢武术，因为非常有意思。

I like martial arts because it is extremely interesting.

Final check

Complete

我常常跑步，也喜欢踢足球。我喜欢武术，因为非常有意思。

I often run and also like playing football. I like martial arts because it is extremely interesting.
