Opinions About Work

Learn how to say whether work experience was interesting, tiring, useful or difficult.

1. Basic opinions

我觉得……

wǒ jué de...

I think...

有意思

yǒu yì si

interesting

无聊

wú liáo

boring

有用

yǒu yòng

useful

我觉得实习很有意思。

I think the work experience was very interesting.

这个经验很有用。

This experience was very useful.

Quick Check

2. Work feelings

累

lèi

tired / tiring

忙

máng

busy

轻松

qīng sōng

relaxed / easy

开心

kāi xīn

happy

工作很忙，所以我很累。

The work was busy, so I was very tired.

同事很友好，所以我很开心。

My colleagues were friendly, so I was very happy.

Check

3. Positive and negative points

优点

yōu diǎn

advantage / good point

缺点

quē diǎn

disadvantage / bad point

压力

yā lì

pressure / stress

难

nán

difficult

这份工作的优点是同事很友好。

The good point of this job is that the colleagues are friendly.

缺点是工作有点儿难。

The bad point is that the work is a little difficult.

4. Using 因为 and 所以

因为

yīn wèi

because

所以

suǒ yǐ

so / therefore

学到

xué dào

to learn / gain

很多

hěn duō

a lot / many

因为我学到了很多，所以我觉得实习很有用。

Because I learned a lot, I think the work experience was very useful.

因为工作很忙，所以我觉得很累。

Because the work was busy, I felt very tired.

Final Check

Complete

我觉得这次实习很有用。因为我学到了很多，所以我很开心。工作很忙，也有点儿累，但是同事很友好。

I think this work experience was very useful. Because I learned a lot, I was very happy. The work was busy and a little tiring, but my colleagues were very friendly.
