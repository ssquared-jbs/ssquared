Complex Opinions

Learn how to make your answers stronger using opinions, reasons and contrast phrases.

1. Giving clear opinions

我觉得……

wǒ jué de...

I think...

我认为……

wǒ rèn wéi...

I believe...

有用

yǒu yòng

useful

重要

zhòng yào

important

我觉得图书馆很有用。

I think the library is very useful.

我认为学校设施很重要。

I believe school facilities are very important.

Quick Check

2. Adding reasons with 因为

因为

yīn wèi

because

所以

suǒ yǐ

so / therefore

安静

ān jìng

quiet

方便

fāng biàn

convenient

我喜欢图书馆，因为那里很安静。

I like the library because it is quiet there.

食堂很方便，所以学生喜欢在那里吃午饭。

The canteen is convenient, so students like eating lunch there.

Check

3. Using 虽然……可是……

虽然

suī rán

although

可是

kě shì

but / however

但是

dàn shì

but

不大

bú dà

not big

虽然学校不大，可是设备很好。

Although the school is not big, the equipment is very good.

虽然食堂很小，但是很干净。

Although the canteen is small, it is very clean.

4. Strong exam-style sentences

不仅……而且……

bù jǐn... ér qiě...

not only... but also...

更

gèng

even more / more

特别

tè bié

especially

对……有帮助

duì ... yǒu bāng zhù

helpful for...

图书馆不仅安静，而且对学习有帮助。

The library is not only quiet, but also helpful for studying.

我特别喜欢实验室，因为设备更现代化。

I especially like the laboratory because the equipment is more modern.

Final Check

Complete

我认为学校设施很重要。虽然我的学校不大，可是设备很好。图书馆不仅安静，而且对学习有帮助，所以我特别喜欢那里。

I believe school facilities are very important. Although my school is not big, the equipment is very good. The library is not only quiet, but also helpful for studying, so I especially like it there.
